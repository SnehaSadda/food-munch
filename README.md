# Food Munch

A responsive food ordering website with a dynamic menu, search, filters and a shopping cart.

## Features
- Responsive layout that works on mobile, tablet and desktop (Bootstrap 4)
- Dynamic menu built with JavaScript, with 8 categories and 16 dishes
- Category filter buttons and live search
- Veg and non-veg markers on every dish
- Shopping cart with quantity controls, discount codes and a running total
- Cart saved in the browser with localStorage, so it survives a refresh
- Video popup and smooth-scrolling navigation
- Accessible design: image alt text, keyboard focus styles and readable button contrast

## Tech Used
- HTML5
- CSS3
- JavaScript (ES6)
- Bootstrap 4
- Font Awesome

## Project Structure
- **index.html**: page structure
- **style.css**: styling
- **menu-data.js**: menu categories and dishes
- **script.js**: menu rendering, filters, search and buttons
- **cart.js**: cart logic

## How to Run
1. Download or clone this repository
2. Open index.html in your browser

## Try the Discount Codes
Add items to the cart and enter MUNCH10 (10% off) or FIRST20 (20% off).
